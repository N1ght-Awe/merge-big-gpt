# 角色素材替换入口

当前资源目录：`public/assets/characters/v3/`。**角色绘制已暂停，等待用户提供独立成品 PNG。用户已确认 `art-reference/角色定稿参考.png` 仅作为角色定稿参考，不直接裁图或重画。** 这里使用已经生成的现有素材维持游戏可运行；07、08 暂时复制自 v2。不要把这套临时组合视为已验收的正式角色美术。

界面采用薰衣草紫、奶油白、樱花粉的糖果工坊主题。角色成品以用户提供的设定板为准：白色长发、紫瞳、花结流苏发饰、蓝白衣装、蓝紫龙尾；整体保持白色主导。此前临时素材的白金造型不作为最终身份约束。

## 替换方法

1. 将 11 张成品透明 PNG 放到本目录，保留下面的文件名；也可新建目录并修改 `src/config.ts` 顶部的 `assets` 路径。
2. 文件名变化时修改 `src/config.ts` 的 `LEVELS[].image`。
3. 建议使用正方形透明图，至少 512×512，人物完整入画。画布中的糖果球由代码绘制，无需烘焙到角色图里。
4. **不要为了换图调整 `radius`**。碰撞始终使用圆形实体，图片透明轮廓不参与物理计算。
5. 更换素材后刷新页面，Canvas 会重新生成各级贴图缓存；检查实际小尺寸下的头部、表情和裁剪范围。

画布构图微调位于 `src/game.ts` 的 `ART_FRAMES`：`scale` 为原图的显示倍率，`y` 为垂直偏移（以球半径为单位）。根据正式立绘调整这些数值即可，不需要修改物理系统。
