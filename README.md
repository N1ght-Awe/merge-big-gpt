# 合成大GPT

把小小的灵感，合成伟大的 GPT 龙娘。基于 **Vite + TypeScript + Matter.js** 的物理合成网页小游戏。无需账号、后端或数据库；角色与音效均不依赖外部服务。

## 启动

在本目录打开终端，使用 Node.js 22.12+（或 20.19+）：

```powershell
npm install
npm run dev
```

打开终端显示的地址，默认 <http://127.0.0.1:5173/>。

```powershell
npm run build     # TypeScript 检查 + 生产构建，输出到 dist/
npm run preview   # 本地预览生产构建
npm test          # 真实 Matter.js 物理与状态回归测试
```

手机与电脑连接同一局域网时，可显式运行 `npm run dev -- --host 0.0.0.0`，然后在手机访问电脑的局域网 IP 和端口。防火墙需允许该本地服务。游戏布局支持触摸操作；无须开放公网。

`dist/` 可部署到静态网站服务器（包含子目录部署）；请通过 HTTP 打开，不要直接双击 `dist/index.html`。

## 怎么玩

- 鼠标左右移动选择落点，单击投放；手机按住拖动瞄准，松手投放。
- 选中画布后，`←` / `→` 或 `A` / `D` 调整位置，`空格` / `↓` 投放，`P` 暂停或继续。
- 两个同级角色碰撞会合为下一级；第 11 级保持在场上，不再合并。
- 当前待投放角色显示在画布顶部；左侧预览是**再下一只**。
- 1.8 秒内连续合并触发 Combo；每多一档增加 20% 基础分，奖励按最高 Combo ×8 计算（最多 2.4 倍基础分），提示可以继续增加。
- 角色持续超出警戒线 2.4 秒后游戏结束，显示「上下文溢出了！」。新落下的角色有 1.6 秒入场宽限。
- 首次合成最高级角色时出现庆祝光芒与特别旋律，之后仍可以继续挑战分数。
- 暂停、帮助和图鉴期间物理时间停止；切到后台或离开浏览器焦点也自动暂停，回来后手动继续。
- 最高分和静音偏好保存在当前浏览器的 `localStorage`；不会保存半途棋盘，也不会跨设备同步。

## 龙娘糖果屋 × 魔法工坊

- 中央糖果瓶棋盘是主视觉，分数与 Next 使用紧凑 HUD，11 级图鉴收进弹出收藏册。
- 薰衣草紫、奶油白为主，辅以樱花粉、薄荷绿与暖金；控制按钮采用圆润的立体糖果造型。
- 角色在带厚边、高光和底影的透明糖果泡泡中显示；立绘只做视觉缩放、轻微倾斜和圆内裁剪。
- 掉落轻弹，合成弹跳、光环和积分浮字，Combo 逐级增强。8–10 级有短庆祝，11 级使用特别光芒。
- 静态背景与 11 级泡泡按需缓存；粒子最多 200 个、合成光环最多 18 个，效果有生命周期并尊重减少动态效果设置。
- `src/physics.ts` 与合成规则保持原有实现；视觉效果不改变物理位置、半径、速度和合成时序。

本次布局、交互和性能检查记录见交付目录的 `UI重构验证.md`。目前的角色仍是临时素材，等待用户提供成品。

## 美术替换与调参

当前游戏使用 `public/assets/characters/v3/` 内的 11 张临时透明 PNG。角色绘制已按用户要求停止，等待用户提供成品；当前采用已完成的白色立绘，其中 07、08 暂时沿用旧版素材。界面的薰衣草紫糖果主题与角色本身的白色主调独立。图鉴弹窗采用大图卡片，可直接查看各级立绘。各级名称、图片路径、颜色、半径、得分和梗文案集中在 `src/config.ts`。

把正式透明 PNG 放到 `public/assets/characters/`，更改对应 `image` 文件名即可。素材建议正方形、主体居中，保留圆形视觉重心；碰撞体始终是 `radius` 定义的圆形，不依赖图片的透明像素。详见 `public/assets/README.md`。

## 实现与验证边界

- 碰撞回调仅收集候选对，`Engine.update` 完成后统一移除旧球、创建新球；同一帧每个实体最多消费一次。
- 同时监听开始接触和持续接触，防止连锁中的接触漏判；状态 `Map` 与 Matter 世界同步维护。
- 采用 60 Hz 固定物理步长并限制每帧追帧数量，避免慢帧或后台返回后时间突然跳变。
- 暂停冻结投放冷却、Combo 和失败倒计时；合并继承已有的越线危险计时，避免利用合并无限续命。
- 音效需第一次鼠标、触摸或键盘操作后由浏览器解锁；音频不可用、贴图加载失败或本地存储被禁用时仍可玩。
- 尊重系统的减少动态效果偏好；图鉴和帮助使用可键盘操作的模态弹窗。

这是可玩的 MVP，已完成糖果屋与魔法工坊 UI 重构；角色目前使用现有临时素材，等待替换用户提供的成品。美术动效深化、长期难度平衡、局面存档和线上排行榜可以继续迭代。已完成的检查和实际试玩范围见同级交付目录的验证记录。

开发时仅在 `npm run dev` 的 `?debug` 页面暴露 `window.__GPT_GAME__` 供场景验收；生产构建不暴露调试入口。
